# 冥 UNDERWORLD OS 5.0 — Hệ Thống Quản Lý Âm Phủ & Phán Quyết Nghiệp Lực

Ứng dụng web quản lý địa phủ phong cách cyber-mythology đóng gói trong **một file `index.html` duy nhất**, tối ưu để chạy trực tiếp trên **Acode**, **TrebEdit** (Android) và xuất bản nhanh qua **GitHub Pages**.

---

## ✨ Tính Năng Nổi Bật

1. **Cổng Quỷ Môn Quan & Telemetry Thời Gian Thực**
   - Tự động quy đổi giờ dương gian sang **Canh Giờ Âm Phủ** (*Tý, Sửu, Dần, Mão...*).
   - Thống kê trực tiếp số linh hồn đang chịu phạt, số người đã đầu thai, tổng điểm **Hắc Nghiệp (Karma)** và thanh tìm kiếm nhanh toàn cục.
   - Tích hợp âm thanh tổng hợp bằng **Web Audio API** (không phụ thuộc file MP3 ngoài).

2. **Tòa Án Diêm Vương AI (Gương Nghiệp Kính Hologram)**
   - Nhập tên, dương thọ, chọn nhanh các tội danh mẫu hoặc tự khai báo tội trạng.
   - Hiệu ứng quét laser, tính toán điểm nghiệp âm, tự động phân tầng địa ngục và lưu ngay vào **Sổ Sinh Tử** (`localStorage`).

3. **Sổ Sinh Tử Điện Tử**
   - Lưu trữ bền vững trên trình duyệt qua `localStorage`.
   - Hỗ trợ lọc theo từng tầng trong 18 tầng địa ngục, lọc theo trạng thái thụ án/đầu thai và nạp dữ liệu mẫu.

4. **Bản Đồ 18 Tầng Địa Ngục**
   - Hiển thị đầy đủ **Thập Bát Tầng Địa Ngục** kèm Cai Ngục AI phụ trách, ngưỡng nghiệp tối thiểu, cơ chế trừng phạt 5.0 và danh sách phạm nhân đang giam giữ tại từng tầng.

5. **Trạm Nạp Công Đức & Quán Trà Mạnh Bà 5.0**
   - Thực hiện công quả (*Quét dọn Cầu Nại Hà, Chép kinh sám hối, Tưới hoa Bỉ Ngạn, Đặc xá*) để đưa thời hạn thụ án về `0 năm`.
   - Chọn hương vị canh/trà Mạnh Bà và cấp **Vé Thông Hành Luân Hồi** qua Cầu Nại Hà.

## 📱 Hướng Dẫn Chạy Trên Acode / TrebEdit & GitHub

### 1. Chạy trên Acode / TrebEdit (Android)
1. Tạo thư mục mới, ví dụ `underworld-os-5`.
2. Tạo file `index.html` (và tùy chọn thêm `README.md`).
3. Dán toàn bộ mã nguồn HTML vào `index.html` và lưu lại.
4. Nhấn nút **Run / Play (▶)** trong Acode hoặc TrebEdit để mở xem trực tiếp.

### 2. Đưa Lên GitHub Pages
1. Tạo một **Repository** mới trên GitHub (chọn **Public**).
2. Tải file `index.html` (và `README.md`) lên nhánh `main`.
3. Vào **Settings → Pages**, tại mục **Branch** chọn `main` và thư mục `/ (root)`, sau đó nhấn **Save**.
4. Truy cập liên kết `https://<ten-tai-khoan>.github.io/<ten-repo>/` sau vài phút để sử dụng.
