Mọi thay đổi được lưu cục bộ trên thiết bị này. Hãy sao lưu JSON để chuyển dữ liệu sang thiết bị khác.

🚀 TRIỂN KHAI TRÊN ACODE • TREBEDIT • GITHUB

Toàn bộ giao diện, hệ thống 18 tầng địa ngục, cơ sở dữ liệu LocalStorage và hiệu ứng âm thanh đã được đóng gói gọn trong 1 file duy nhất (index.html) để bạn chạy mượt trên điện thoại:

1. Chạy trên Acode / TrebEdit (Android):

Tạo thư mục mới underworld-os-6.0 → Tạo file index.html → Dán toàn bộ mã nguồn vào → Nhấn nút Play (▶) góc trên cùng để chạy ngay lập tức.

2. Đưa lên GitHub Pages miễn phí:

Tạo Repository mới trên GitHub → Upload file index.html → Vào Settings → Pages → Branch: main → Lưu lại để nhận link web chia sẻ cho bạn bè.
